StepCrumbs is ready

Leave a trail of crumbs as you work: every click, field and command becomes a step in a guide you can post to LinkedIn or your website. Free and local.

  1. Pin the iconClick the puzzle-piece icon in the toolbar, then the pin next to StepCrumbs.
  2. Open what you're working in, then the side panelProxmox, the AWS Console, Azure, GitHub, your router… any web UI. Click the StepCrumbs icon and the panel opens on the right.
  3. Create a project and press Start recordingGive it a name like “3-node Proxmox cluster” or “Static site on S3 + CloudFront”. You can stop and come back to the same project on another day.
  4. Work normallyEvery click becomes a step with a highlighted arrow. Typing in fields and commands in browser terminals (Proxmox Shell, xterm.js-based cloud shells) are captured too. Password fields are hidden automatically, and account IDs, ARNs, keys, emails and public IPs on screen are auto-blurred. Press Alt+Shift+M before typing any other secret.
  5. Log what was hard as it happensOpen the Notes tab: add a Challenge when something breaks, then a Solution once you fix it. They land at the right spot in your guide.
  6. Stop, then click “Editor & export”Read through, blur what's sensitive and star the key steps.
  7. Write it up with ClaudeClick Write with Claude → Download pack. Attach the pack in Claude and tell it what the recording can't show: why you built it, what went wrong, what fixed it. Paste Claude's reply back into the same dialog, and your guide, SOP, carousel, video and web page update.
  8. ExportA LinkedIn carousel PDF and post, a short video, a printable SOP, or a website page.

Keyboard shortcuts

Alt+Shift+PPause / resume recording
Alt+Shift+MMute typing (passwords, API keys, Wi-Fi keys)
Alt+Shift+STake a manual screenshot step (great for showing a result)
Alt+Shift+NJump to the Notes tab

To change them, open chrome://extensions/shortcuts (or edge://extensions/shortcuts).

Good to know

Private by design

No account, no cloud, no cost. Everything is stored in your browser on this PC. Use Backup in the editor to keep a copy.

What it records

  • Clicks in any browser tab (incl. iframes)
  • Text typed into fields
  • Commands in xterm.js terminals and noVNC consoles

What it can't record

  • Apps outside the browser (PuTTY, Windows Terminal, VS Code). Use a browser shell, or add the command as a code block in the editor
  • chrome:// pages and the Web Store

Before you publish

Check the Privacy check panel in the editor. Auto-blur catches common secrets, but glance over each screenshot for anything else (hostnames, serials, MAC addresses).
